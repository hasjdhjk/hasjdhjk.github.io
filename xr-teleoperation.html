From human motion to robot demonstrations

The goal is to use an XR headset and controllers to guide robot manipulation in simulation, then record demonstrations that can support imitation learning. This page separates that intended workflow from the setup and experiments completed so far.

The intended workflow

01 / OperatorMeta Quest 3 headset and controller pose input
02 / SimulationMap operator motion to a Unitree robot in Isaac Sim
03 / LearningRecord demonstrations and evaluate manipulation policies

This is a conceptual project workflow. The final end-to-end XR demonstration and autonomous grasping evaluation are still to be established.

Early-stage Unitree robot configuration

A short clip from the early configuration of the physical Unitree robot, showing the hardware setup stage of the project.

Current progress

  • Worked on early configuration of the physical Unitree robot, shown in the video above.
  • Worked on the Isaac Sim and Unitree simulation environment and associated Python tooling.
  • In related BiGym2 work, ran a random-agent baseline and opened the Move Plate demonstration viewer.
  • Launched an ACT-style offline-training check; the saved run contains a policy checkpoint, metadata and evaluation recording files.

The current record does not establish successful end-to-end XR arm control, a completed demonstration dataset, or a validated autonomous grasping result. ACT and Diffusion Policy are the next imitation-learning methods of interest.

Next experiments

  • Verify pose mapping and stable XR control inside the simulator.
  • Record and inspect demonstration trajectories.
  • Measure imitation-policy performance on fresh evaluation episodes.

The configuration clip above records my early hardware setup. The cover image remains an upstream Unitree simulation reference; my own simulation screenshots and a full XR teleoperation demonstration will be added as the project progresses.
